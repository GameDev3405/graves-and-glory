# Install guide

**You need:** a Minecraft: Java Edition account, Java 17 or newer, and Prism Launcher (or another launcher that imports `.mrpack` files).

**Steps**
1. Download the latest Graves and Glory `.mrpack` from **[PACK LINK — Kort to fill in]**.
2. In Prism Launcher choose **Add Instance → Import**, and select the `.mrpack` file. Prism sets up Minecraft 1.20.1, Fabric Loader and every mod for you.
3. Launch the new instance and sign in. The first start takes a while.
4. At the title menu pick **Enter camp**, then use **Play with friends** or the server browser. Server address: **[SERVER ADDRESS — Kort to fill in]**.

**Version mismatch?** The game kicks you with an update message if your pack doesn't match the server. Download the newest `.mrpack`, re-import it, and try again.

**Performance tips**
- Shaders start off. Pick one under *Visuals & sound* in the lobby if your PC can handle it.
- Give the instance 4 GB or more of RAM in Prism's settings.

**Still stuck?** Post in #install-help with your launcher, Java version and the exact error text or a screenshot.
