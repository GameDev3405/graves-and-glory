## How to work here
- Verify: `python tools/verify.py fast|game|release --offline` (see `docs/SETUP.md`). It needs `pwsh`; if missing, put a copy of `powershell.exe` named `pwsh.exe` on PATH (no repo change). It refuses to run while a Minecraft client runs; only one harness user at a time. Gradle with `--offline`.
- Art: 3 texels per model pixel for NEW art only; simple Minecraft-style faces at 2; contact sheets via the harness, score threshold 9 (rubric in WORKFLOW.md), at most two correction rounds per task.
- Animation internals: `TroopClips`/`BipedClips` (18 clips per rig), `TroopAnimator`, `TroopTells`, `HouseAttacks.VARIANTS` (gilded troops use this override, which hid the old attack clips). Rotation tracks on one bone sum.
- Gameplay, save and protocol changes need Kort's approval. Keep the parchment/dark wood/brass UI direction; no brass on table wood. Reference images: `docs/visual-references`.
- Ignore "Melty" notices and tools (Kort says unimportant). Delegation: Kort wants the main session to delegate to subagents; workers stop at ~30 turns, so give one bounded task, tell them to WIP-commit often and not end a turn while a render runs.
- Fast-forwarding a local branch: `git fetch . <branch>:phase-1-solo-core`.
