## What was implemented

- `sheets/design.json` `botCommand`: the single row is replaced by `easy` / `normal` / `hard` with the brief's numbers (Normal = the old 0.25 / 0.6 / 1.5, decisionTicks 100). `Spec.java` was regenerated by `python tools/preflight.py` (not hand-edited); `sheets/preflight.json` filledCells 1222 -> 1251.
- `BattleMath`: `leastDefended`, `timedCharge`, `shieldwallVsArchers`, exactly as in the brief's interfaces.
- `Campaign`:
  - `String difficulty = "normal"`; command `difficulty:<id>` (unknown ids are ignored; it is in the `global` list, so it is refused with the usual "Active battle choices are locked" notice while `b.running`; when a custom lobby is open only its leader may set it); snapshot field `"difficulty"`.
  - `prepareRound` sets `s.tier = difficulty` for every bot it creates. The mid-battle stand-in bot made in `Battle.leave()` also takes `campaign.difficulty`.
  - `tier(Squad)` returns the row by id, falling back to `normal`.
  - The inline loop in `tick` is split. Economy (training queue, respawn delay) stays on the 100-tick beat. `botDecide(Squad, BotCommandRow)` runs when `b.time % tier.decisionTicks() == 0` (Easy 160, Normal 100, Hard 60). `Spec.BOTCOMMAND[0]` no longer appears in code; `tier(s)` replaces it.
  - `botDecide` is the old loop body. Easy and Normal use the old lane formula and the global enemy count, so Normal is unchanged. Hard picks its point with `leastDefended` over all `b.points.size()` points (defenders = team sightings within 2 x point radius), times its charge on the nearest remembered enemy (near count = sightings within 2 x chargeDistance), and gives infantry a `shieldwall` assignment when remembered archers within 30 blocks number at least 3, no remembered enemy infantry is within 8 blocks, and the army has shield troops. The charge horn is kept.
- `GravesAndGlory.Squad.tier` (String, default `"normal"`).
- `CampaignClient.difficulty`, `botsLabel()`, `nextDifficulty()` (cycles in sheet order easy -> normal -> hard -> easy). Snapshot parsing tolerates a missing field.
- `CampScreen` home page: a "Bots: <Tier>" button (greyed while a battle runs) with a muted one-line help text; the screen's state key includes the difficulty so it redraws. `CampaignLobbyScreen` lead controls: "Bot fill" and "Bots: <Tier>" side by side on one row; its state key includes the difficulty.
- `Tactics` (a one-clause deviation, see Concerns): a `shieldwall` formation now raises shields whenever the trooper has a target, not only within 6 blocks.
- `docs/PARKED.md`: one appended line about the shield raise range.
- `test-tools`: 5 new `BattleMathCheck` checks (20 in total) and the `bots` suite in `Phase1Checks`; `skirmish(...)` now sets `Campaign.difficulty`.
