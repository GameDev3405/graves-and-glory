# Map Forge 2A.3 report, 2026-10-30

**Outcome.** Implemented and unit-tested. Nothing is accepted in game yet. Branch `work/mapforge-2a3` (from main bd05fa2). Commits: 057b256 (the package), plus this report. Nothing pushed.

**Files.** `tools/mapforge/` holds `nbt.py`, `structure.py`, `world.py`, `plan.py`, `cli.py`, `__main__.py` and `README.md` (the format spec). Samples are `samples/camp-watchpost.json` and `camp-protect.json`. Tests are in `test-tools/standalone/test_mapforge.py`.

**Format.** Plans use `gg-mapforge-plan/1`. It has five ops: `set`, `fill` (solid, hollow or outline, with an optional replace list), `clear`, `structure` (uses the `Structures.place` pivot and rotation, turns block states, structure void keeps what is there) and `terrain` (a heightmap stamp). Plans also carry allow/deny region locks and an optional `--protect` deny file, a `maxChangedBlocks` limit and an optional `expectWorld` digest. Dry-run prints the digests, counts, box and blocks placed or removed. Apply writes an undo record first and never overwrites one. Rollback refuses if any block the plan wrote was edited since.

**Tests.** 16 mapforge tests pass. The full standalone Python suite passes (176 tests). `verify.py fast` (Gradle) was not run, because no Java changed.

**Assumptions.**
- The offline world is a JSON file of sparse cells. Paths inside a save (`level.dat`), `builder-server` or `GGBuild` are refused.
- Entities in structure files are kept but not placed.
- Rotation turns `facing`, `axis`, `rotation`, rail shape and the four side properties only.
- `clear` is allowed inside the locks. 7.3's "may not delete a region" is enforced only through the locks and limits.
- preflight.py cannot be imported, so its NBT logic was reimplemented. Every shipped structure file round-trips byte for byte.
