# Port audit: 1.20.1 to 1.21.1 (PORT-1, P0 and P1 prep)

2026-11-08. Research and docs only; no product code changed. Written on `prep/port-1211-audit` from `main` `d051dd19`. Companion to `2026-11-07-port-1211-and-plain-clients.md` (P0 and P1 tables there).

**How to read the evidence.** "Read" means I read the code in this checkout (greps and file reads, 2026-11-08). Claims about 1.21.1 APIs come from Fabric's published changelogs and my own knowledge of the 1.20.5 to 1.21.1 changes. No Minecraft 1.21.1 sources or jars were available (no downloads allowed), so **every claim about a 1.21.1 signature is unverified until the toolchain compiles**; the table marks each as U (unverified, expected) or C (confirmed by a source I read). Web searches this session confirmed only: Java 21 is required from 1.20.5 on (Fabric's 1.20.5 post), the Fabric 1.21.1 porting guide exists, Fabric API has 0.102 to 0.106+ builds for 1.21.1, and Distant Horizons has 1.21.1 Fabric builds.

## 0. Summary

- Source: 164 main Java files plus 24 mixins (39k lines). The build is Loom 1.7.4, Yarn 1.20.1+build.10, Fabric API 0.92.2, `options.release = 17`.
- The big jobs, in order of size: networking (19 channels), HUD/canvas rendering and the vertex API (`BodyCache`, 128 `RenderSystem` hits), mixins (24), props (item_display NBT), test harness (152 test-tools Java files plus `ggbot.py`), item NBT, `Identifier` (76 sites).
- Important new fact beyond the 2026-11-07 plan: `anim/geckolib-rebuild` adds **GeckoLib 4.8.4 for 1.20.1** (`geckolib-fabric-1.20.1`, jar-in-jar, plus `mclib:20`). The port must switch to GeckoLib's 1.21.1 line (existence of a matching 4.x build for 1.21.1: unverified; GeckoLib's `1.21.1` artifact naming is expected). Porting before that branch merges means doing the animation engine twice, so the freeze list below puts it first.
- Second new fact: the prop kit (`Props`, `PropMenu`) is in `main` already and spawns `item_display` entities by hand-built NBT with `item.tag.CustomModelData`. That format is gone in 1.21 (components). It is an extra item-NBT site the 2026-11-07 plan did not count (it counted 4).

## 5. Top risks

1. **Networking rewrite touches every feature** (19 channels, hand-built `state_v10`). A byte-level mismatch looks like a gameplay bug. Mitigation: codecs wrap the existing write/read order; dedicated-server test per channel.
2. **GeckoLib is mid-flight.** Porting before `anim/geckolib-rebuild` merges duplicates work, and the 1.21.1 GeckoLib line is unconfirmed. Mitigation: freeze list entry 1; check GeckoLib's 1.21.1 artifact before the freeze starts.

4. **Rendering/vertex API changes** (`BodyCache`, `ModelPart.render` color int, `tickDelta` to `RenderTickCounter`, 28 `DrawContext` files). Wide but mechanical; risk is visual regressions that only a screenshot review catches.
5. **Props and item data** (`item_display` NBT, 41 structure NBTs with old item formats, saved prop entities) fail silently (invisible props, empty chests), no crash to point at them. Needs an explicit load-all test.
Also: test harness size (152 files, `ggbot.py` protocol rewrite) and the builder-server mods (Axiom, Ledger, Xaero versions unknown).
