# Plain clients P4: formations, relics and the War Table for vanilla players (2026-11-16)

Scope: Kort, 2026-11-16 evening (status/DECISIONS-2026-11-15-port.md, "next wave"). Plain clients P4 covers formations,
relics and the other War Table pages for vanilla players. This reverses, for this phase, the narrow cut of the same day.
Base: the 2026-11-07 port plan's P4.1 to P4.6, cut to that scope. The order is formations, relics, then the War Table pages.
Out of scope: P4.1 mob disguises (P3 already has them), P4.5 pack art beyond what the menus need, and the P4.6 hub nudge.
Branch `plain/p4`, worktree `bb-plain-p4`, base main 5d4efb1b1 (P3 49a4e7557 included).

## Hard rules
- **No mod ids.** A vanilla client never receives a mod registry id, a custom payload, or an item it cannot render.
  - Every menu stack is a vanilla item. Names and lore are plain text, with no keybind or translation keys from the mod.
  - The harness also range-checks item ids in container and slot packets (new in P4).
- **Dupe-safe menus.** No chest menu ever moves an item.
  - Cases covered: taking an item out, shift-click, number-key and offhand swap, drag, double-click collect, Q and ctrl-Q, clicks outside, and close while holding.
  - Each case has a pure check and a live harness check.

## Decisions settled here (report them; ask Kort only if one fails in play)
1. **One menu base, `PlainMenu`.**
   - Every plain chest page extends it. It never calls the vanilla click logic.
   - Only a plain left or right `PICKUP` on a button slot inside the menu runs that slot's command. Every other action type and slot is refused.
   - After each click it resyncs the whole screen and the cursor (to empty).
   - The decision lives in the Minecraft-free `PlainMenuRules`, pinned by the standalone `PlainMenuRulesCheck`.
   - A page redraws in place (same window) where it can.
2. **Battle hotbar pages, using the swap-hand key (F).**
   - **Orders page** (P3): keys 2 to 6 are orders.
   - **Tactics page:** keys 2 to 5 are the four formations (Shield wall, Banner, Wedge, Loose). Keys 6 to 8 are relic slots 1 to 3. Key 9 is the Armoury.
   - F switches page in battle; the action bar names the page.
   - The mouse wheel from slot 0 reaches only slot 1 (a formation or an order, both free of cost) or slot 8. Slot 8 holds no relic, so one wheel notch can never spend a relic.
   - In camp, F does nothing: the hotbar keeps the War Table book (slot 7) and the practice compass (slot 8).
3. **Formations use the modpack path.**
   - A formation key calls `OrderRules.playerOrder(.., "formation", id, ..)`, as the modpack's tactical_v2 does.
   - The chosen shape is kept per plain player and passed on every later hotbar order, so a Hold keeps the shape. The modpack does the same on the client.
4. **Relics.**
   - In battle, a relic key sends `relic:<slot>` (`Commander.activate`).
   - Readiness shows on the tactics page: item count = seconds left, a vanilla item cooldown sweep, and lore. It also shows in the action bar.
   - The loadout is chosen in camp on the Gear page with `gear:relic:<slot>:<id|->`.
5. **War Table as chest menus.**
   - Slot 7's book becomes the War Table. Home is a hub with buttons to Recruit (P3), Banner, Contracts, Chapter, Friends, Field, Results and Gear. In battle, the Armoury opens from the tactics page.
   - Each page reads server state (Profile, Campaign, SocialHub) and sends the modpack page's own command string through `Battle.command`. Every rule and refusal stays the modpack's.
   - Camp stations (`PlainClients.station`) open their page instead of "needs the modpack".
6. **Text input.** No anvil or sign screens, since they add dupe surface.
   - Banner names keep their defaults (rename stays modpack-only).
   - Invites pick from the online players.

## Tasks
### P4.F Formations (first)
- `PlainClients`: tactics page, F switch (mixin on the swap-hand action, plain only), formation keys, per-player shape used in `order()`.
- The HUD shows the shape by its label.
- Harness: F, then the Wedge key; then Hold. Server state shows `formation=wedge` on the hold assignment.
- **Done when:** all four shapes can be set from keys; Hold keeps the shape; a plain client receives no payload.

### P4.R Relics
- Tactics page relic items: the vanilla item per slot, name, readiness and cooldown sweep. Keys go through `relic:<slot>`.
- Action bar readiness.
- Any relic feedback that reaches modded players only as a payload gets a plain stand-in: chat or action-bar text, vanilla sounds.
- **Done when:** a plain player can fire an equipped relic in battle and see its cooldown.

### P4.W War Table pages
- `PlainMenu` base and the Recruit page moved onto it.
- Pages:
  - **Home:** the hub, practice, the next March battle.
  - **Banner:** pick the banner (`banner:use`), new, copy and delete, paint cells (`cell:`), and colour.
  - **Contracts:** claim, reroll, weekly.
  - **Chapter:** claim, titles.
  - **Friends:** party and room via `social:`; invites from online players.
  - **Field:** maps and bot tier.
  - **Results:** the last match.
  - **Gear:** equip, unequip, relic slots, forge roll, breakdown, repair and expand.
  - **Armoury** (in battle): train, disband, cancel, troop gear.
- Station routing; stale "needs the modpack" texts updated.
- **Done when:** each page is reachable and each modpack action on it is available, except banner rename (Decision 6).
