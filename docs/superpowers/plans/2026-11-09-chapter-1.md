# Chapter 1 "The Oath": build plan (2026-11-09)

Brief: `bannerbound-lore` `docs/lore-lead:docs/lore/chapter-1-build-brief.md` (design: `chapter-1-battles.md`). Branch `campaign/chapter-1`, worktree `bb-campaign`, cut from `main` `a7811c4d`. Kort approved scope 2026-11-09 (`status/DECISIONS-2026-11-09.md`).

## Shape

- New sheet `campaignChapters`, one row per chapter: `id` (oath), `chapter` (1), `name` (The Oath), `house`, `banner` (own or house), `bannerRow` (botBanners id or none), `season` (1), `chapterEnd`, `placeholder`. Chapters 2 to 5 are added as rows here plus their `campaignBattles` rows; no code change.
- `campaignBattles` gains `enemies` (botBanners ids by lane, or none), `after` (win line), `ebb` (bool).
- Pure logic in `MarchMath` / `MarchText` / `ProfileMigration` (compiled by `verify.py fast` and tested by the standalone checks); `Campaign` and the client only call it.
- Season dates: `config/gravesandglory/seasons.json` beside the server (or the client's game dir for solo), `{"starts": ["YYYY-MM-DD", ...]}`, season n starts on `starts[n-1]`. Missing file: season 1. Season 1 is always open.
- Spec.java and sheets/preflight.json are regenerated by preflight and never committed (coordinator rule).
